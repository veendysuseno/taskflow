# TaskFlow

TaskFlow adalah aplikasi Task Manager sederhana yang dibuat menggunakan:

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## Features

- Add task
- Delete task
- Complete task
- Task filtering
- Search task
- Priority system
- Deadline
- Progress bar
- Task statistics
- Dark mode
- Responsive design
- LocalStorage
